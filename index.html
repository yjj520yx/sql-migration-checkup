它怎么判断

改写规则

把语义确定、写法可替换的部分直接改掉，例如 VARCHAR2 → VARCHAR、LIMIT 100,20 → LIMIT 20 OFFSET 100。

建议改写，不自动应用

拿不准的给出建议写法、标「需人工确认」，但不写进输出，例如 (+) 外连接、ROWNUM 分页、ON DUPLICATE KEY UPDATE、ENUM。宁可少改，也不改错。

风险分级

高 语义或结构会变 · 中 依赖版本/参数 · 低 写法统一、基本无风险。

已知限制 不连库、不执行 SQL；不保证语义完全等价；存储过程/触发器只识别不改写；规则覆盖有限，复杂写法请人工复核。
  • 转换结果用于迁移前的改造提示，不能替代在目标达梦库上的实测。
  • 规则按「高频、可解释」挑选，v1 覆盖 — 条，不是全集。
  • 所有 SQL 仅在浏览器内存中处理，不发送到任何服务器，也不写入磁盘。
  • 涉及金额、时间、字符长度语义的改动，即使标为低风险，也建议回归测试。
